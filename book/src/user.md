# User documentation

These pages describe Zebra 7.0.0 for node operators and for the software that
depends on their nodes.

- **Deploy:** [requirements](user/requirements.md),
  [platforms](user/supported-platforms.md), [installation](user/install.md),
  [configuration](user/config.md), [running](user/run.md),
  [Docker](user/docker.md). A [state snapshot](user/snapshots.md) avoids a
  sync from genesis.
- **Operate:** [upgrading](user/upgrading.md), [tracing](user/tracing.md),
  [metrics](user/metrics.md), [health endpoints](user/health.md),
  [troubleshooting](user/troubleshooting.md).
- **Integrate:** [JSON-RPC](user/rpc.md), [Zallet](user/zallet.md),
  [lightwalletd](user/lightwalletd.md), [mining](user/mining.md). Operators
  leaving `zcashd` start with the
  [API migration guide](user/zcashd-api-migration-guide.md) and
  [zcashd-compat mode](user/zcashd-compat.md).
- **Test networks:** [custom testnets](user/custom-testnets.md),
  [Regtest](user/regtest.md), [forking the Testnet](user/fork-zebra-testnet.md).
